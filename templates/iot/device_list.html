Data flow

  1. An ESP32 with a load cell (or a scanner gateway) measures the shelf/bin.
  2. It sends the reading over HTTPS (POST /api/v1/iot/readings/) or MQTT (sis/<device_id>/readings) with its device key and a unique message id.
  3. The server validates the device, the timestamp and the value, and drops duplicate deliveries.
  4. Weight is converted to units using calibration and compared with the stock ledger.
  5. Differences beyond tolerance raise an alert. Stock is never changed automatically: staff verify the reading, which posts an auditable count correction.
